# 普通页面首屏启动调整 — 2026-11-20

前一轮已将普通页面的初始样式从 96,318 字节降到 1,664 字节，并延后构建设置表单。用户仍反馈页面显示慢。本轮继续调整主初始化的执行时机，没有修改 HVUT，也没有将 JPX-PLUS 改成扩展。

## 行为变化

普通可见页面在 DOM 就绪后，先释放脚本注入任务，通过 `requestAnimationFrame` 后的 `setTimeout` 给浏览器一次绘制机会，再执行 `jpxMain()`。这减少首次绘制前阻塞的工作，不代表初始化工作全部消失，也不保证浏览器每次都先绘制。

战斗、谜题、独立记录页和隐藏页面仍立即初始化。等待期间发生按键、指针按下、点击、配置变更或表单提交，会在 window 捕获阶段立即启动，让新安装的 document 处理器接收同一次事件；不重放事件。页面隐藏或离开时也会启动，避免配置跟踪依赖前台动画帧。
